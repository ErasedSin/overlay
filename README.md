# overlay

Páginas para usar como fonte de Navegador no OBS.

- `controles.html`: mostra o controle (PS4) e o teclado/mouse enquanto você joga. Os dados chegam criptografados do programa "Enviar Controles", que roda no PC onde o controle e o teclado estão ligados. Sem o código do link (`#k=...`), a página não mostra nada.
- `livepix-obs.html`: os widgets do LivePix num layout 16:9.

`keyboards/` são os modelos de teclado do [NohBoard](https://github.com/ThoNohT/NohBoard), feitos pelos autores de cada pasta.
